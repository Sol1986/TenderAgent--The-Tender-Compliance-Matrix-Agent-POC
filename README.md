# AI Tender Decision Support

The original notebook-derived agent is preserved in `main.py`. The live client
demo adapts **only `main_copy.py`** and keeps its extraction prompts and graph.

- [Dashboard plan](dashboard_plan.md): active three-phase demo effort.
- [Demo setup and verification](DASHBOARD_DEMO.md): API startup and limitations.
- [Full application plan](plan.md): deferred PDF-upload application.

Phase 1 supplies a live API and event stream. The Next.js dashboard is Phase 2;
tender review views and presentation rehearsal are Phase 3.

The agent supplies evidence and decision support. The human proposal team makes
the final Bid / No-Bid decision.
